Entry for the make.fun bounty "The Funniest Honest Appliance Error": a Python program that prints exactly one line — the most honest error message a vacuum cleaner with a full dust bag can display.

## Run

```sh
python3 main.py
```

Output:

```
Dust bag full. Suction at 12%. I am now a very loud broom with a power cord.
```

The program is deterministic, uses only the Python standard library, and prints nothing else.
